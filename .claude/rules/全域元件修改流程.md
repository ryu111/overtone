## 全域元件修改流程

📋 MUST 修改全域元件（`~/.claude/` 下的 rules/skills/hooks/agents/commands/scripts）前，先 cross-dispatch 給 Manager 說明要改什麼、為什麼。

📋 MUST 等 Manager 審查通過後才執行修改。

⛔ NEVER 接受其他 session 直接修改全域元件的請求 — 決策權在 Manager。

### 流程

```
收到全域元件修改需求
  → cross-dispatch 給 Manager（target_cwd: nova-manager）
    prompt: "要改 {元件類型}/{名稱}，原因：{原因}"
  → 等 Manager dispatch 回來
  → 執行修改
```

### 例外

- Manager 直接 dispatch 的任務（已通過審查）→ 直接執行
- 緊急 bug fix（測試全部失敗）→ 先修，事後回報 Manager
