# Nova Control App 關鍵時刻通知觸發表

> Nova Control App (iOS/macOS) 透過 SSE 接收 nova-server 事件，觸發本地推播通知。

## SSE 事件 → 通知對應

| # | SSE 事件類型 | 觸發時機 | 通知 Title | 通知 Body | 優先級 |
|---|------------|---------|-----------|----------|:------:|
| 1 | `sd:done` | 自驅完成一輪 | Nova 自驅 | ✅ 完成 {n} 個任務 · 測試 {pass}/{total} | low |
| 2 | `sd:circuit-break` | 熔斷觸發（連續失敗） | Nova 自驅停止 | 連續 {n} 次失敗，已熔斷。需要你檢查 | critical |
| 3 | `sd:decision-pending` | 新增待決定事項 | Nova 需要你 | 有 {n} 個待決定事項等你處理 | high |
| 4 | `test:regression` | 測試回歸偵測 | Nova 品質警報 | 測試從 {before}% 降到 {after}% | high |
| 5 | `quality:decline` | 品質分數下降 | Nova 品質警報 | {component} 品質 {before}→{after} | medium |
| 6 | `task:completed` | 單一任務完成 | Nova {project} | 完成：{task_name} | low |
| 7 | `milestone:reached` | L5 產品里程碑 | Nova {project} | {project} 完成 {n}/{total} 任務 | medium |
| 8 | `ask_question` | Interactive Ask（已有） | Nova {project} | {question_preview} | high |

## App 端接收邏輯

### iOS (IOSViewModel.handleSSEEvent)
```swift
// 新增 notification 事件處理
if event.type == "notification" {
    let title = event.title ?? "Nova"
    let body = event.body ?? ""
    let urgency = event.urgency ?? "low"
    let id = "notif-\(event.event ?? "unknown")-\(Date.now.timeIntervalSince1970)"

    // 所有 urgency 都發通知（App 在前景時也顯示 banner）
    sendLocalNotification(title: title, body: body, id: id)

    // critical → 加震動
    if urgency == "critical" {
        // iOS haptic feedback
    }
}
```

### macOS (NovaViewModel)
```swift
// 新增 UNUserNotificationCenter（macOS 10.14+）
import UserNotifications

// 在 setupSSE 的 onEvent 中加入：
case "notification":
    if let data = payload.data(using: .utf8),
       let notif = try? JSONDecoder().decode(NotificationEvent.self, from: data) {
        sendMacNotification(title: notif.title, body: notif.body)
    }
```

## nova-server 端 emit 邏輯

### 廣播 helper (scripts/flow/api-router.js 或 heartbeat.js)
```javascript
function broadcastNotification(ctx, event, title, body, urgency, data = {}) {
    ctx.emit('notification', {
        type: 'notification',
        event,
        title,
        body,
        urgency,
        data,
        ts: Date.now()
    });
}
```

### 觸發點
| 觸發點 | 檔案 | 位置 |
|--------|------|------|
| 自驅完成 | heartbeat.js | handler 的 finally 區塊 |
| 熔斷 | heartbeat.js | checkCircuitBreaker() |
| 待決定新增 | decisions.js (新) | writePendingDecision() |
| 測試回歸 | heartbeat.js (Phase 2) | evaluate() 比對 snapshot |
| 品質下降 | wrapup.js Phase B | judge 評分後比對 |
| 任務完成 | heartbeat.js | spec-tasks.js complete 後 |
| 里程碑 | heartbeat.js (Phase 3) | L5 支線偵測進度 |

## 去重規則

同一事件類型 5 分鐘內不重複通知（避免連續 tick 轟炸）：
- `sd:done` → 每 30 分鐘最多 1 次
- `sd:circuit-break` → 不去重（一定要通知）
- `sd:decision-pending` → 每 10 分鐘最多 1 次
- `test:regression` → 每 30 分鐘最多 1 次
- 其他 → 每 5 分鐘最多 1 次
